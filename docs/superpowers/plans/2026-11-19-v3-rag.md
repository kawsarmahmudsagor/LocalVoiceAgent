# v3 RAG and Playground Tabs Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Answer from uploaded `.txt`/`.md`/`.pdf`/`.docx` documents through a Chroma index, with switchable Hugging Face and Ollama embedders, a timed `retrieval_ms` stage, and Playground / System Prompt / RAG tabs.

**Architecture:** A new `server/voicebot/rag/` package (loaders, chunker, embedders, store, library, service). `RagService` owns one indexing worker thread and answers `retrieve(query)` on the turn thread. `VoiceSession` calls it between STT and the LLM, logs the result and sends RAG events over the existing WebSocket. Uploads use new HTTP routes. The web app gains tabs and two new panels.

**Tech Stack:** Python 3.12, FastAPI, chromadb (embedded `PersistentClient`), sentence-transformers, pypdf, python-docx, python-multipart, httpx (already installed through `openai`); React 18 + Vite + vitest.

**Spec:** [docs/superpowers/specs/2026-11-19-v3-rag-design.md](../specs/2026-11-19-v3-rag-design.md). Read it first; section numbers below (§) refer to it.

- bge query prefix, exact: `"Represent this sentence for searching relevant passages: "` (queries only).
- Default RAG template, exact (§3.3):

  ```
  {context}
  ```
- Ask the user before any `sudo`, and stop and ask if dependencies conflict (Task 1).

## Review Focus

1. **A template with other braces** (e.g. `"Use {notes} wisely: {context}"`) must not crash a turn: fill it with `str.replace("{context}", ...)`, never `str.format`. Test in Task 7.
2. **The same file uploaded twice**, or the same content under another name, must not create duplicate chunks: dedupe by sha256 and report "already indexed". Test in Task 5.
3. **A long text with no punctuation or line breaks** (pasted logs, a one-line `.md`) must still chunk to at most `size` characters with the overlap. Test in Task 2.
4. **An Ollama model that is not pulled** (HTTP 404) must fail the switch with a clear reason and keep the previous embedder. **A model whose vector size differs from its saved collection** (the model was re-pulled or replaced) must rebuild that collection, never query it with the wrong size. Tests in Task 6.
5. **Deleting a document while it is still queued or indexing** must leave no chunks and no manifest entry behind. Test in Task 6.

- [ ] **Step 3: Implement `load_text` and `chunk`**

`load_text`: dispatch on `path.suffix.lower()`; `.pdf` → `pypdf.PdfReader(path).pages[i].extract_text()` joined by `"\n\n"`; `.docx` → paragraph texts then table cell texts, one per line; strip; raise `NoText` if the result is empty.

`chunk`: normalise runs of spaces/tabs to one space and 3+ newlines to `"\n\n"`. Split recursively on the first separator from `["\n\n", "\n", ". ", "! ", "? ", " ", ""]` that splits a too-long piece, then greedily merge pieces up to `size`. A carried-over tail plus the next piece must still fit `size`; if not, shorten the tail. Drop empty chunks.

  ```python
  @dataclass(frozen=True)
  class RagSettings:
      enabled: bool = False; top_k: int = 3; min_score: float = 0.5; max_context_chars: int = 2000
      chunk_size: int = 800; chunk_overlap: int = 120; embedder: str = "hf:BAAI/bge-small-en-v1.5"
      def updated(self, patch: dict) -> "RagSettings"   # validates; ValueError listing every bad field; unknown keys are bad
  INDEX_KEYS = ("chunk_size", "chunk_overlap")
  @dataclass
  class DocRecord: doc_id: str; name: str; ext: str; size: int; sha256: str; state: str; chunks: int = 0
  # state: "queued" | "indexing" | "ready" | "no text" | "failed: <reason>"
  class Library:
      def __init__(self, root: Path) -> None          # files in root/"files", manifest root/"manifest.json"
      def add_file(self, name: str, data: bytes) -> tuple[DocRecord, bool]   # bool: newly added; same sha256 -> (existing, False)
      def documents(self) -> list[DocRecord]          # upload order
      def get(self, doc_id: str) -> DocRecord | None
      def path(self, doc_id: str) -> Path
      def set_state(self, doc_id: str, state: str, chunks: int | None = None) -> None
      def remove(self, doc_id: str) -> bool
      def load_settings(self, default: RagSettings) -> RagSettings   # root/"settings.json"; missing/corrupt -> default
      def save_settings(self, s: RagSettings) -> None
  ```
  `doc_id` is the first 12 hex chars of the sha256. The manifest is written atomically (temp file + `os.replace`).

- [ ] **Step 3: Implement `RagService`**

One worker thread reads jobs `("index", doc_id)`, `("delete", doc_id)` and `("reindex",)` from a `queue.Queue`. Indexing loads, chunks with the current settings, and embeds in batches of 32 under `self._lock` (one batch per lock hold, so `retrieve` waits at most one batch). `delete` first marks the doc so a pending `index` job for it is skipped, then deletes chunks, file and manifest entry. `update`: validate with `RagSettings.updated`; if `embedder` changed, build the new embedder **outside** the lock, embed `["probe"]` to learn `dim`, then swap under the lock; if the target collection is missing, has another `dim`, or has other chunk settings, `reset` it and queue `reindex`. A change to an `INDEX_KEYS` value also resets and queues `reindex`. Persist with `Library.save_settings`, then emit `config_event()`. Any exception while building or probing the new embedder becomes `RagError(str(e))` and the settings stay unchanged.
