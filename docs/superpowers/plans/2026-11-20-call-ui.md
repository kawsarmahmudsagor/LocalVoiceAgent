# Call UI page (`/call`) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a `/call` page to `web/` that ports the TelcoAIAgent call screen (avatar, status, waveform, mic / End call / speaker, collapsible right conversation pane) on top of the existing voice-bot WebSocket session, leaving `/` unchanged.

**Architecture:** Two Vite pages: `index.html` (playground, plain CSS) and `call.html` (Tailwind v4 + motion, loaded only there). The session logic moves from `App.tsx` into a `useVoiceSession` hook that both pages use. The server serves `dist/call.html` at `GET /call`.

**Tech Stack:** React 18, Vite 5, TypeScript, Vitest (`renderToStaticMarkup`, no jsdom), Tailwind CSS v4 (`@tailwindcss/vite`), `motion`, `lucide-react`; FastAPI + pytest on the server.

**Spec:** `docs/superpowers/specs/2026-11-20-call-ui-design.md`

**Telco reference code:** read the ported files with
`git -C ../TelcoAIAgent show a1d8317^:frontend/components/app/call/<file>` (call-avatar, call-waveform, call-controls, call-chat, conversation-pane, status.ts) and
`git -C ../TelcoAIAgent show a1d8317^:./frontend/components/agents-ui/blocks/agent-session-view-01/components/agent-session-block.tsx` (layout).
Port the look and behaviour; replace LiveKit hooks with the `useVoiceSession` interface below.

## Global Constraints

- `/` must look and behave exactly as before. Tailwind and its preflight are imported only from `web/src/call/`.
- No settings, model pickers, prompt, RAG or latency readout on `/call`.
- Telco card overlay (packages, confirm codes) and LiveKit are not ported.
- Do not reuse Telco's `agent-avatar.svg` (it is branded "Horizon Realty agent"); draw a neutral avatar.
- Do not edit `RealtimeSTT/` or `RealtimeTTS/`.
- Tests run without GPU, Docker, network or models. Web: from `web/`, `npm run test && npm run typecheck && npm run build`. Server: from `server/`, `../.venv/bin/python -m pytest -v` (Windows: `..\.venv\Scripts\python -m pytest -v`).
- Component tests use `renderToStaticMarkup` like `src/components/RagPanel.test.tsx`; do not add jsdom or testing-library.
- Stage files by explicit path. Never `--no-verify`. End each commit message with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- Visual work (Tasks 5–7) uses the `frontend-design` skill for direction; Task 7 ends with a `ui-ux-pro-max` accessibility / touch-target / reduced-motion pass.

## Review Focus

1. **Mic permission denied on Start call** — the call screen still opens, mic shows off, the error shows under the status, typing works. Test: Task 7 `callFlow` "start with mic error".
2. **End call while the assistant is speaking** — playback stops at once, the conversation clears, and a late `assistant_*` event for the old turn does not repopulate the screen. Pinned by: Task 4 keeps `stop()` (cut playback) before `clear()` as today; Task 7 End handler calls them in that order and `flow.test.ts` "end resets"; Task 7 Step 7 manual check ends a call mid-reply.
3. **Speaker muted across a sample-rate change or a new call** — mute survives player recreation; a new call starts unmuted. Test: Task 3 `setMuted` before worklet load; Task 7 "end resets speaker".
4. **`/` already open (session_busy)** — the start screen shows the error and Start is disabled while disconnected. Test: Task 7 `StartScreen` markup.
5. **Narrow screen** — the pane covers the call, is `inert` when closed, Escape closes it and returns focus. Test: Task 6 `ConversationPane` markup (`inert`, `data-open`, `aria-label`).

### Task 4: Extract `useVoiceSession`

**Files:**
- Create: `web/src/session/useVoiceSession.ts`
- Modify: `web/src/App.tsx` (session code moves out; JSX unchanged)

**Interfaces:**
- Consumes: Task 3 `Player.setMuted`, `Player.level`, mic `level`.
- Produces:

```ts
export interface VoiceSession {
  state: AppState;
  dispatch: Dispatch<Action>;
  /** Exclusive-guarded; resumes the player first (user gesture). */
  toggleMic(): Promise<void>;
  send(text: string): void;
  /** stop_speaking + cut playback (the current onStop). */
  stop(): void;
  /** clear + flush (the current onClear). */
  clear(): void;
  selectModel(role: Role, slug: string): void;
  /** Dispatches "settings" and sends a 300 ms debounced update_settings (the current onSettingsChange). */
  updateSettings(patch: Partial<Defaults>): void;
  updateRag(patch: Partial<RagSettings>): void;
  resumeAudio(): void;
  /** Remembered and re-applied when the player is recreated on a sample-rate change. */
  setSpeakerMuted(muted: boolean): void;
  agentLevel(): number; // player.level(), 0 without a player
  userLevel(): number;  // mic.level(), 0 while the mic is off
}
export function useVoiceSession(init?: (s: AppState) => AppState): VoiceSession;
```

`init` is the `useReducer` initializer; `App` passes its `initState` (tab from localStorage).

- [ ] **Step 1: Move the code** — everything in `App.tsx` from the refs through `onUpdateRag` except tab handling moves into the hook with the names above. `App` keeps `onTab`, `ragDisabled`, `reportRagError` and its JSX, now calling `session.*`.
