# Barge-in Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let the user interrupt the bot by speaking, with two switchable trigger modes, a heard-text history cut, and barge-in latency in the turn logs.

**Architecture:** RealtimeSTT keeps recording on voice between `text()` calls, so the session only stops muting the mic during a turn. It listens to four recorder callbacks and fires the existing `_stop_speaking` path. The browser flushes its player on a new `barge_in` event and reports the text it revealed (`playback_cut`). The server stores that text in history. `TurnTimer` gains barge marks and spans, and a "hold" that keeps the interrupting utterance's STT marks for the next turn.

**Tech Stack:** Python 3.12, FastAPI, pytest; React + TypeScript, vitest. RealtimeSTT and RealtimeTTS vendored and untouched.

**Spec:** `docs/superpowers/specs/2026-11-20-barge-in-design.md`

## Global Constraints

- Do not edit `RealtimeSTT/` or `RealtimeTTS/`.
- Branch `feat/v3-barge-In`. Stage files by explicit path. Never `--no-verify`. End every commit message with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- Tests run without a GPU, Docker, network or models. Server: from `server/`, `../.venv/bin/python -m pytest -v` (Windows: `..\.venv\Scripts\python -m pytest -v`). Web: from `web/`, `npm run test && npm run typecheck && npm run build`.
- `barge_in_mode` values: exactly `"off"`, `"onset"`, `"words"`. Default `"off"`.
- `barge_in_min_ms`: int, 0–1000 inclusive, not bool. Default `200`.
- With mode `"off"`, behaviour and timings are unchanged (mic muted during a turn, no new waits).
- Event and command names exactly: `barge_in {turn_id}`, `playback_cut {turn_id, heard}`, `assistant_done {text, interrupted, heard}`.
- Marks: `barge_onset`, `barge_in`, `playback_cut`. Spans: `barge_detect_ms` (`barge_onset` → `barge_in`), `barge_cut_ms` (`barge_onset` → `playback_cut`). Record fields: `barge_in_mode`, `barge_in_min_ms`, `barge_false_triggers`, `heard`.
- **False trigger (refines spec §2.3/§2.4):** one voice episode during an armed turn that ended without firing. In `onset` mode: a speech pause (`on_turn_detection_start`) before the min-ms timer ran out. In `words` mode: a recording stop before any non-noise partial. Counting each noise partial would count one cough many times.

## Review Focus

1. **Cough, then keep talking (`onset`).** The pause cancels the timer, but RealtimeSTT does not fire `on_recording_start` again in the same recording. Speech resuming (`on_turn_detection_stop` while recording) must re-arm the onset. Test in Task 4: `test_onset_rearms_when_speech_resumes`.
2. **The interrupting utterance's own timing.** Its `speech_end` / `endpoint` / `stt_start` arrive during the old turn. Without the hold they would corrupt the old turn's spans (a typed turn would take `speech_end` as its origin) and be wiped by the old turn's `timer.reset()`. Test in Task 1 (`test_hold_keeps_input_marks_for_next_turn`) and Task 4 (`test_barge_utterance_timing_goes_to_next_turn`).
3. **`playback_cut` arriving before the server starts waiting for it.** The browser answers `barge_in` at once; the server may still be inside `audio.play()`. The ack must be stored, not lost. Test in Task 5: `test_cut_ack_before_wait_is_kept`.
4. **Stop with mode `off` still cuts history.** Stop is not a barge-in, but spec §3 gives it the same cut. Test in Task 5: `test_stop_button_uses_heard_text`.
5. **Recorder `on_turn_detection_stop` right after a recording ends** (see the comment in `stt.timing_callbacks`). It must not re-arm an onset when no recording is active, or a phantom barge-in fires on silence. Test in Task 4: `test_resume_after_recording_stop_does_not_arm`.

### Task 4: Session arming, triggers and fire

**Files:**
- Modify: `server/voicebot/session.py`
- Test: `server/tests/test_session.py`

**Interfaces:**
- Consumes: Task 1 (`hold`, barge stages), Task 3 (settings).
- Produces, all public on `VoiceSession` and safe to call from recorder threads at any time:
  - `on_recording_start() -> None`: `self._recording = True`. If armed and not fired: mark `barge_onset`. In `onset` mode, start the min-ms timer (`threading.Timer`; fire at once when `barge_in_min_ms == 0`).
  - `on_recording_stop() -> None`: `self._recording = False`. In `words` mode, if armed and not fired: count a false trigger and unmark `barge_onset`.
  - `on_speech_pause() -> None` (recorder `on_turn_detection_start`): in `onset` mode, if armed and not fired and a timer is pending: cancel it, unmark `barge_onset`, count a false trigger.
  - `on_speech_resume() -> None` (recorder `on_turn_detection_stop`): in `onset` mode, if armed, not fired, `self._recording` is true and no timer is pending: mark `barge_onset` and start the timer again.
  - `on_partial(text)`: as today, plus: in `words` mode, if armed and not fired and `not is_noise(text)`, fire.
- Arming rules (spec §2):
  - At turn start, after `user_transcript`, read mode and min-ms once. Armed when mode is not `"off"` and either the turn is a voice turn or `self._listening` is true.
  - When armed: do not call `audio.mute_input(True)` (and so not `mute_input(False)` either), and call `self.timer.hold()`.
  - Disarm (cancel any timer) in the turn's `finally` before `timer.reset()`, in `_stop_listening`, in `_clear`, and in `close`.
- Fire (once per turn, guarded by a `_barge_fired` flag under `_state_lock`): mark `barge_in`, emit `{"type": "barge_in", "turn_id": turn_id}`, then call `self._stop_speaking({})`.
- `_finish_metrics` records add `barge_in_mode` (the turn's mode, `"off"` when unarmed), `barge_in_min_ms`, `barge_false_triggers` (int, per turn).

### Task 5: History cut from `playback_cut`

**Files:**
- Modify: `server/voicebot/session.py`
- Test: `server/tests/test_session.py`

**Interfaces:**
- Consumes: Task 4 (fire).
- Produces:
  - New command `playback_cut {turn_id: int, heard: str}` in `handle()`. Stored only when `turn_id` equals the current turn and `heard` is a string. It sets an event and marks `playback_cut` on the timer. Otherwise it is ignored silently (no error). State is cleared at turn start, so an ack that arrives before the server waits is kept.
  - In `_run_turn`, for an interrupted turn in browser mode (`self.audio.output_format is not None`): wait up to `self.ack_timeout` for the ack. Then:
    - ack with non-empty `heard`: stored reply = `heard`.
    - ack with empty `heard`: no `add_exchange`.
    - no ack: stored reply = the full reply.
  - Server mode and uninterrupted turns do not wait.
  - `assistant_done` gains `heard`: the acked text for an interrupted turn with an ack, else `None`. It is emitted after the wait. The APOLOGY and TTS-failure `assistant_done` events also carry `"heard": None`.
  - The metrics record gains `heard` (same value).
